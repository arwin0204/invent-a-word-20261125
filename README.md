An entry for the make.fun bounty [Invent a Word We Need](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0): coin one new English word and define it in a single clear line of at most 140 characters.

## The word

**tabnesia** (n.) — the blank moment after opening a new browser tab and forgetting what you meant to look up.

*Tab* + *amnesia*: English has no word for that small daily lapse, and everyone who has ever opened a tab recognises it at once. The blend follows a familiar English pattern (brunch, sitcom, hangry), so it is sayable, spellable and memorable.

## How it works

`main.py` is fully deterministic — no randomness, no network, no input files. It writes the single-line entry (106 characters) to `/output/entry.txt` and self-checks it against the gate first: one line, 1–140 characters, not only white space, valid UTF-8.

Run it:

```sh
python3 main.py
```
